# VELOURA — Luxury Beauty Storefront

A premium, motion-rich beauty storefront built as a lightweight static experience for Cloudflare Workers Static Assets.

## Highlights
- Luxury editorial art direction
- Responsive mobile-first layout
- 3D tilt interactions and ambient canvas motion
- Product filtering and quick-view modal
- Persistent local cart with drawer UI
- Newsletter interaction and micro-animations
- Zero framework runtime overhead

## Deploy
Cloudflare Workers Builds can deploy this repository with the default deploy command:

```bash
npx wrangler deploy
```

The site is served from `./public`.
